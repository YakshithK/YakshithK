# I'm Yakshith, building tools for running and training AI models and for computer use.

## What I'm working on

- `unsloth` — local UI to run and train LLMs and diffusion models.
- `ollama` — tools for running Kimi-K2.6, GLM-5.2, MiniMax, DeepSeek, gpt-oss, Qwen, and Gemma models.
- `cua` — open-source drivers, cross-OS sandboxes, and benchmarks for computer use.
- `SimpleFlightController` — Python project.
- `aerivoice` — native macOS dictation with Soniox transcription and configurable AI cleanup.
